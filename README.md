# CSE 210: Programming with Classes

Welcome to my **CSE 210: Programming with Classes** repository.

This course builds on fundamental programming concepts and introduces **C#** and **object-oriented programming (OOP)**. The goal is to learn how to design, build, test, and improve programs using classes and objects.

## Course Focus

Throughout this course, I will develop my understanding of:

* C# programming fundamentals
* Variables and data types
* Conditional statements
* Loops
* Methods and parameters
* Lists and collections
* Classes and objects
* Constructors
* Encapsulation
* Abstraction
* Inheritance
* Polymorphism
* Object-oriented program design
* Debugging and testing
* Code organization and maintainability

## Learning Approach

I will approach each programming problem using a step-by-step process:

1. **Understand the requirements**
2. **Identify the objects**
3. **Identify the attributes**
4. **Identify the behaviors**
5. **Design the classes**
6. **Write the C# code**
7. **Run and test the program**
8. **Debug errors**
9. **Refactor and improve the code**

## Goal

The main goal of this course is not simply to write code that works, but to understand **how and why the code works**.

By the end of CSE 210, I aim to be comfortable designing programs using object-oriented principles and applying those skills to larger software development projects.
